# Newsroom | Social Media Analytics

Posting more does not always mean better results. I built this Power BI report to explore which content gets a response, how platforms compare, and when audiences interact with posts.

The report covers five fictional media brands across Facebook, Instagram, X, and YouTube.

## Inside the report

- **Overview** — Impressions, interactions, and engagement trends.
- **Content** — Performance by topic, format, and story.
- **Publishing** — Posting patterns and response over time.
- **Platforms** — Engagement, link clicks, and video performance.
- **Story detail** — A closer look at one story across platforms.

Light and dark themes, a collapsible filter panel, and drillthrough help keep the report easy to explore.

## About the data

The synthetic dataset contains **30,000 posts**, **12,000 stories**, and **882,124 daily records** covering **2024–2025**.

All brands, stories, and performance figures are fictional. The data was created for this portfolio project and does not represent real business results.

## Tools

Power BI · Power Query · DAX · Python

The model includes separate activity and publication date tables, with 40 measures organized into display folders.
